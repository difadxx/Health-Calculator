Калькулятор ИМТ и нормы калорий на Python

Описание проекта:
Это мой проект на Python - простой и удобный калькулятор здоровья, работающий в консоли. Программа рассчитывает Индекс Массы Тела (ИМТ) человека и определяет суточную норму калорий, которая нужна для поддержания веса.

Как это работает:
1. Сбор данных. Программа просит пользователя ввести вес в кг, рост в сантиметрах, возраст и пол. Числа вводятся целыми, что очень удобно в реальной жизни.
2. Расчет ИМТ. Рост переводится в метры, после чего рассчитывается сам индекс. Результат округляется до двух знаков после запятой через встроенную функцию round.
3. Анализ веса. Через обычные условия if, elif и else программа проверяет получившийся ИМТ и выводит текстовый статус: дефицит веса, норма, избыточный вес или ожирение.
4. Расчет калорий. Суточная норма энергии считается по стандартной научной формуле. В коде через оператор or настроена проверка пола для маленьких и больших букв, чтобы программа не ломалась от случайных ошибок при вводе.

Что использовалось в коде:
- Консольный ввод и вывод данных (команды input и print)
- Цепочки условий if, elif, else и логический оператор or
- Математические действия: возведение в степень, деление и функция округления round
